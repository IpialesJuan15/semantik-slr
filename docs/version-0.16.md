# Versión 0.16 · Dirección visual expresiva

Se aplicó la skill UI/UX Pro Max al diseño de Semantik SLR usando la referencia de portafolio creativo aportada por el investigador. La portada presenta un título de mayor jerarquía, bordes visibles y vistas previas numeradas con los IDs reales de las revisiones. La mesa de lectura adopta la misma identidad visual sin sacrificar la claridad del resumen, el PDF y la decisión humana.

Se añadieron dos animaciones breves: la entrada de la portada y la apertura del expediente. Con `prefers-reduced-motion: reduce` ambas quedan estáticas. No se añadieron estudios ficticios, un equipo inventado ni un formulario de contacto de agencia. La paleta continúa clara, violeta y sin verde o azul oscuro.

En Windows: detén `iniciar.bat`, ejecuta `git pull --ff-only origin feature/llm-nube-opcional`, inicia otra vez y recarga el navegador con `Ctrl+F5`. `/api/status` debe indicar `0.16.0`. No hay dependencias nuevas.
